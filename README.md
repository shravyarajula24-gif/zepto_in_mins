# 🛒 Zepto Quick Commerce – SQL Data Analysis

## 📌 Project Overview

This project focuses on analysing a quick-commerce business using **MySQL**. The objective is to explore order transactions, revenue generation, inventory levels, store performance, delivery efficiency, and customer purchasing patterns.

Using SQL queries, I analysed business data to identify meaningful insights that can help improve operational efficiency, inventory management, and customer satisfaction.

## 🎯 Business Problem

Quick-commerce businesses face challenges in managing inventory, tracking deliveries, monitoring store performance, and understanding customer purchasing behaviour.

The goal of this project is to use SQL to analyse business operations and answer important business questions related to sales, orders, inventory, delivery performance, and customer trends.

## 🗂️ Database Structure

The project consists of four tables:

| Table Name | Description |
|---|---|
| `dark_stores` | Contains store details, locations, managers, and daily capacity. |
| `hub_staff` | Stores employee and rider information, including ratings and roles. |
| `inventory_items` | Contains product details, categories, vendors, prices, and stock quantities. |
| `instant_orders` | Stores order details, customer information, payment modes, and delivery status. |

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **IDE:** MySQL Workbench
- **Language:** SQL

## 📊 Key Business Questions & Analysis

The project covers 20 SQL business questions, including:

1. Calculate total revenue from successfully delivered orders.
2. Identify the total number of cancelled orders.
3. Retrieve details of all dark stores.
4. Identify products with stock quantities below 50.
5. Calculate the number of Cash on Delivery (COD) orders.
6. Find the total number of orders received by each store.
7. Analyse category-wise item counts and average prices.
8. Calculate the number of deliveries completed by each rider.
9. Analyse sales revenue by payment mode.
10. Calculate daily order counts.
11. Identify orders delivered faster than the average delivery time.
12. Find the top five localities based on average order value.
13. Identify delayed orders along with store and rider details.
14. Find the top five most-ordered products.
15. Calculate store-wise delivery delay percentages.
16. Rank riders based on average delivery time.
17. Identify the best-selling product category in each store.
18. Identify peak business periods: Morning, Afternoon, Evening, and Night.
19. Create a view to analyse monthly order and revenue trends.
20. Create a stored procedure to analyse revenue based on delivery status.
